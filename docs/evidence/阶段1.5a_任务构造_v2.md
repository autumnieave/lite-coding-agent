## 种子来源

| 工作流 | train-v5 轨迹出现次数 | 变体族 |
| --- | ---: | --- |
| `W1` train-v5 single-read extraction | 78 次（单文件读取） | `policy_extract` |
| `W2` train-v5 list_dir -> selective read -> aggregate | 20 次（list_dir -> read_file） | `selective_aggregate` |
| `W3` train-v5 grep -> read -> collect | 15 次（read_file -> grep -> list_dir -> read_file） | `search_collect` |
| `W4` train-v5 read -> edit -> re-read verify | 14 次（read_file -> edit_file） | `edit_verify` |
| `W5` train-v5 read/list_dir -> multi-file reconcile | 11 次（list_dir -> read_file -> grep -> read_file） | `audit_reconcile` |

## 冻结与不重叠校验

- `validate_stats_specs()` 校验 15 个任务 ID、prompt、fixture seed 唯一，并校验 5 个族 × 3 层（easy/medium/hard 各 5）；同时与 train-v1..v5、dev/tuning、final-test-v2 的保留 ID/seed 集合求交；无交集。
- 每个任务冻结前重新生成 fixture，并校验 prompt 引用的文件、行号、token 与 fixture 一致。
- `fixture_sha256` 对目录内所有文件的相对路径和字节内容做 SHA-256；manifest SHA 对 15 条 canonical spec JSONL 做 SHA-256。
- 任务只用于 stage-1.5 held-out 评测，不进入 SFT train-v5/v6，也不与 final-test-v2 混用。
